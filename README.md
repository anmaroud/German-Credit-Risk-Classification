German Credit Risk Classification

This project was developed as part of my Bachelor's thesis in Digital Systems at the University of Piraeus.

The project focuses on data preprocessing, exploratory data analysis and classification using Python.

Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn.

Methods:

Data cleaning and handling missing values

Exploratory data analysis and visualisation

Outlier detection using the IQR method

Classification using Random Forest, Decision Tree and k-Nearest Neighbours

Model evaluation using accuracy, classification reports and confusion matrices
